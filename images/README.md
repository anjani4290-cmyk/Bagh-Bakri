# images/

The game board and pieces are drawn entirely in SVG at runtime (see
`src/js/render.js`) — no image files are needed for gameplay itself.

This folder is where you'd put:

- Store listing screenshots (see `assets/README.md` for exact sizes
  required by Google Play and the Apple App Store)
- A promotional/social-share image
- A logo for a landing page, if you build one around `index.html`

Nothing here is referenced by the game code, so it's safe to add or
remove files freely.
