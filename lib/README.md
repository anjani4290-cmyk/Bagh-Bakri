# lib/

The game is written in plain, dependency-free JavaScript — no
frameworks or third-party libraries are required to run it.

This folder is reserved for any third-party script you might add
later (e.g. an analytics snippet, a sound library, an ads SDK if you
monetize). Drop the file here and reference it with a `<script>` tag
in `index.html`, above `src/js/board.js` if the library needs to be
available before the game code loads.

Nothing here is required for the game to run as-is.
